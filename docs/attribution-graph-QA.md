你的理解已经抓住主线了。关键是区分两种“路径”：**残差流与注意力内部的传播路径**，以及 **经过多个 MLP 神经元节点的归因路径**。这里的“直接”是针对第二种路径说的。

**1. 是的，图解释的是一次特定输入、特定参考运行下的计算。**

先给定一个 prompt，做一次正常前向，记录注意力模式、门控、归一化分母、神经元激活等。

随后构造一个局部替代模型：

- 固定注意力模式、归一化分母等非线性系数；
- 保留 embedding、残差流、value 路径的线性传播；
- 对 MLP 使用参考运行确定的分账规则。

所以不是“固定了一条传播路径”，而是**固定了一整套传播规则，里面仍然包含大量同时存在的路径**。

也不是“除了神经元激活，其他变量的数值全部固定”。例如，改变一个源神经元的激活后，残差流、注意力的 value，以及目标的 gate / up 输入仍然可以随之改变；只是它们之间的相关映射固定了。

因此，你可以把 attribution graph 理解为：

> 在当前 prompt 的参考状态下，选定冻结方式和 MLP 分账规则后，得到的虚拟线性计算网络。

这里“线性”还需要加一个限定：half 规则构造的系数**不是原模型的真实局部导数**，所以它不是普通的一阶泰勒展开。

---

**2. 是沿层方向展开的，但一条直接边可以跨越很多层、很多 token 位置。**

把一个层中全部 token 的残差堆起来，冻结后的层计算可以写成：

\[
h_{\ell+1}
=
R_\ell h_\ell+D_\ell a_\ell,
\]

其中：

\[
R_\ell=I+H_\ell N_{\mathrm{in},\ell}.
\]

这里：

- \(h_\ell\)：整段序列的层输入残差；
- \(a_\ell\)：这一层全部位置的 MLP 激活；
- \(D_\ell a_\ell\)：MLP 写入；
- \(H_\ell\)：冻结后的注意力或 DeltaNet 输运；
- \(R_\ell\)：残差直通加上冻结的 token 混合。

因此，前一层所有位置可以一起作为一个“状态”，层号就是你说的传播“时间”。

但 token 位置也有约束。对神经元源 \(s=(m,\tau,i)\) 和目标 \(j=(\ell,t,k)\)，只有满足

\[
m<\ell,\qquad \tau\le t
\]

才可能有边。

注意，“前期 token 的早期激活”应包括**目标当前 token 自己的早期层激活**。而同层较早 token 的 MLP 激活不会直接影响同层较晚 token 的 MLP：这一层的注意力发生在这一层的 MLP 写入之前。

---

**3. \(J_{s\to j}\) 已经汇总很多内部路径，但没有经过其他 MLP 的输入→输出计算。**

假设源位于第 \(m\) 层。它写入：

\[
\delta h_{m+1}=d_s\,\delta a_s.
\]

这份写入沿冻结输运传播到目标第 \(\ell\) 层：

\[
\delta\hat x_\ell
=
\underbrace{
N_{\mathrm{post},\ell}
R_\ell R_{\ell-1}\cdots R_{m+1}
}_{J_{m\to\ell}}
d_s\,\delta a_s.
\]

取其中相应 token 的矩阵块，就得到 \(J_{s\to j}\)。

为什么说 \(J\) 已经包含多条路径？例如，暂时把 norm 吸收到 \(H\) 中：

\[
R_2R_1
=
(I+H_2)(I+H_1)
=
I+H_1+H_2+H_2H_1.
\]

这四项分别对应：

1. 全程走残差直通；
2. 经过第一层注意力；
3. 经过第二层注意力；
4. 依次经过两层注意力。

而 \(H_2H_1\) 内部还对中间 token 位置求和：

\[
(H_2H_1)_{t,\tau}
=
\sum_r(H_2)_{t,r}(H_1)_{r,\tau}.
\]

因此：

> **\(J\) 是“不经过中间 MLP 非线性”的所有残差／注意力输运路径之和。**

计算这种直接效应时，中间 MLP 的激活被视为独立的源；不会随着当前源的变化继续重算。

---

**4. \(A_{s\to j}\) 是图上的直接贡献；它通过 \(J\) 包含上述内部路径。**

对目标神经元，half 规则定义固定读出向量：

\[
b_j=
\frac{\sigma(g_j^*)}{2}
\left(
u_j^*W_g[j,:]^\top+
g_j^*W_u[j,:]^\top
\right).
\]

于是：

\[
\boxed{
w_{s\to j}=b_j^\top J_{s\to j}d_s
}
\]

\[
\boxed{
A_{s\to j}=a_s w_{s\to j}.
}
\]

三个步骤就是：

\[
\underbrace{a_sd_s}_{\text{源写入}}
\;\longrightarrow\;
\underbrace{J_{s\to j}}_{\text{冻结输运}}
\;\longrightarrow\;
\underbrace{b_j^\top}_{\text{目标分账}}.
\]

**这里的“直接”不等于“只走一层”，而是“没有经过另一个 MLP 神经元作为中介”。**

例如，L2 的神经元可以有一条直接边到 L20：这条边经过中间多层的残差与注意力，但不包含“源改变 L8 神经元，L8 再改变 L20”这类连锁效应。

---

**5. 若允许经过中间神经元，才得到图上的全路径贡献。**

假设图中有：

\[
s\to j,\qquad s\to k\to j.
\]

那么直接贡献是：

\[
A_{s\to j}=a_sw_{s\to j}.
\]

包含中间神经元 \(k\) 的总贡献则是：

\[
C_{s\to j}
=
a_s\left(
w_{s\to j}
+
w_{s\to k}w_{k\to j}
\right).
\]

更一般地：

\[
\boxed{
C_{s\to j}
=
a_s
\sum_{p:s\rightsquigarrow j}
\prod_{(u\to v)\in p}w_{u\to v}.
}
\]

注意，路径上相乘的是 **虚拟权重 \(w\)**，不是已经乘过源激活的边贡献 \(A\)。

| 量 | 汇总什么 | 经过中间 MLP 神经元？ |
|---|---|---|
| \(J_{s\to j}\) | 残差、冻结注意力等内部输运路径 | 不经过 |
| \(A_{s\to j}\) | 源经 \(J\) 输运后，对目标的直接分账 | 不经过 |
| \(C_{s\to j}\) | 神经元图上所有路径的权重乘积之和，再乘源激活 | 可以经过 |

你说的“路径积分”在这里更准确地叫 **离散路径求和**：网络有限、按层无环，因此是有限条路径的乘积再求和。它与推导 half 规则时使用的 integrated gradients——沿连续缩放参数 \(\alpha\) 做积分——是两件不同的事。
